# Modules

Modules have some magic methods.

## gdo_module_config

You return a list of GDT that are module settings only changeable by admins.

## gdo_user_config

You return a list of GDT that are user settings only changeable by code or admins.

## gdo_user_settings

You return a list of GDT that are user configurable via settings, like his language or timezone.
